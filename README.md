# شبكتي (Shabakti)

تطبيق أندرويد لإدارة شبكة الواي فاي في البيت.

## بيعمل إيه

| الميزة | بتشتغل على |
|---|---|
| حالة الواي فاي: اسم الشبكة، قوة الإشارة، السرعة، التردد، الـ IP، الراوتر، الـ DNS، وهل فيه إنترنت | كل الراوترات |
| فحص الشبكة واكتشاف الأجهزة المتصلة وزمن استجابتها | كل الراوترات |
| اسم كل جهاز وعنوان الـ MAC والشركة المصنّعة وهل متوصل بواي فاي ولا كابل | الراوترات المدعومة بعد تسجيل الدخول |
| التعرف على نوع الراوتر لوحده | كل الراوترات |
| لوحة تحكم الراوتر جوه التطبيق، ومعاها خطوات الحظر لكل نوع | كل الراوترات |
| تسمية الأجهزة وقايمة بالأجهزة المحظورة | كل الراوترات |
| ريستارت الراوتر من التطبيق | Huawei ONT و ZTE (تجريبي) |
| سجل تشخيص تنسخه وتبعته علشان ندعم موديلات جديدة | كل الراوترات |

### الراوترات اللي ليها تحكم تلقائي

- **Huawei ONT**: موديلات HG8145V5 و EG8145V5 و HG8245H و HG8546M، راوترات الفايبر بتاعة WE.
- **ZTE**: موديلات H188A و H168A و H169A و H288A و F670L و F6600 و F6640، اللي بتستخدمها WE وفودافون وأورنج واتصالات.

أي راوتر تاني بيشتغل عن طريق لوحة التحكم اللي جوه التطبيق.

## إزاي تطلّع ملف APK (من غير كمبيوتر)

1. اعمل حساب مجاني على github.com.
2. اعمل Repository جديد، وارفع فيه كل ملفات المشروع وانت محافظ على ترتيب الفولدرات، ومعاها الفولدر `.github`.
3. GitHub هيبدأ يبني التطبيق لوحده. تقدر تتابع البناء من تبويب **Actions**، وبياخد حوالي 5 دقايق.
4. لما البناء يخلص، افتح صفحة **Releases** في الـ Repository ونزّل `Shabakti.apk`.
5. افتح الملف على الموبايل، ووافق على "التثبيت من مصادر غير معروفة" لو الموبايل طلب كده.

## ملاحظات

- لازم تكون عارف اسم المستخدم والباسورد بتوع لوحة تحكم الراوتر. غالبًا مكتوبين على ستيكر ورا الراوتر.
- أندرويد 10 وأحدث مش بيسمح للتطبيقات تشوف عنوان الـ MAC للأجهزة. عشان كده الـ MAC واسم الجهاز بيظهروا لما تسجّل دخول على الراوتر.
- أجهزة كتير الأيام دي بتستخدم MAC عشوائي (Private MAC). لو اتحظر جهاز بالـ MAC بتاعه، ممكن صاحبه يغيّر الـ MAC ويرجع يتصل. الحل الأضمن إنك تغيّر باسورد الواي فاي.
- الحظر بيحصل جوه الراوتر نفسه عن طريق MAC Filter أو Access Control. التطبيق مش بيهاجم الأجهزة ولا بيتدخل في الاتصال بينها وبين الراوتر.

## إضافة دعم لراوتر جديد

اكتب كلاس جديد بيعمل implement لـ `RouterDriver` في `app/src/main/java/com/shabakti/app/router/`، وسجّله في `RouterDetector.driverFor`.

ولو عايز تعرف الراوتر بيستخدم أنهي طلبات، افتح سجل التشخيص من زرار ⓘ في التطبيق.
